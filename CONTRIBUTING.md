# Contributing to AI Memory Hub OSS

Thank you for your interest in contributing!

## Getting started

1. Fork the repository.
2. Create a feature branch.
3. Install the project:
   python -m pip install -e .
4. Make your changes.
5. Run the tests:
   python -m unittest discover -s tests -v
6. Open a pull request.

## Guidelines

- Keep changes focused and documented.
- Add tests for new features and bug fixes.
- Respect project isolation and local-first design.
- Do not submit private conversations, credentials,
  API keys, or personal information.
- Discuss major architectural changes in an issue
  before implementation.

## Reporting bugs

Open a GitHub issue with reproduction steps,
expected behavior, actual behavior, and your
Python version. Remove sensitive information
from logs before sharing.
