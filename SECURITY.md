# Security Policy

## Supported Versions

Security fixes currently target the latest
version on the main branch.

## Reporting Vulnerabilities

Please do not publish security vulnerabilities
in public GitHub issues.

Use GitHub's private vulnerability reporting
feature if enabled for this repository.

Do not include real credentials, personal
conversations, or sensitive database contents.

## Current Limitations

This early version does not provide encryption,
authentication, or multi-user access controls.

Do not expose the application as a public service.
