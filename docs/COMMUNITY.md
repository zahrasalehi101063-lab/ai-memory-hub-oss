# Community and Contributions

We welcome bug reports, documentation improvements,
test cases, and focused pull requests.

## How to contribute

1. Search existing GitHub Issues.
2. Open an issue describing the proposed change.
3. Create a branch for your contribution.
4. Keep changes small and well documented.
5. Run `python -m pytest -q`.
6. Open a pull request explaining your changes.

## Bug reports

Include:
- Python version and operating system
- Steps to reproduce
- Expected and actual behavior
- Relevant sanitized error messages

Do not share passwords, API keys, private memories,
or personal data in public issues.

## Security

Report suspected vulnerabilities according to
SECURITY.md rather than disclosing sensitive
exploits in public issues.

## Project status

AI Memory Hub OSS is an early-stage open-source
project. Community adoption is still developing.
